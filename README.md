# 👻 IziGhost

**IziGhost** — это продвинутый ИИ-ассистент для Linux-десктопа, глубоко интегрированный в систему через D-Bus и Wayland. Он сочетает в себе удобный HUD-интерфейс поверх всех окон, возможности распознавания экрана и голоса, а также мощный фоновый демон для работы с LLM.

---

## ✨ Ключевые особенности

* 💬 **Продвинутый чат с LLM**
  Поддержка OpenAI-совместимых API. IziGhost собирает контекст системы и позволяет взаимодействовать с моделями в реальном времени.

* 👁️ **Распознавание текста (OCR)**
  Встроенная интеграция с Tesseract (`leptess`) для моментального захвата и распознавания текста с экрана.

* 🎤 **Голосовой ввод (ASR)**
  Поддержка диктовки и распознавания речи, что позволяет общаться с ассистентом без использования клавиатуры.

* 🎥 **Real-time Video Monitoring System (RVMS)**
  Захват экрана или отдельных окон через **PipeWire**. Ассистент буквально "видит", что происходит у вас на экране, для более точных и контекстных ответов.

* 📄 **Умная обработка документов**
  Встроенный парсинг PDF, офисных документов и изображений с использованием библиотеки `kreuzberg`.

* ⚙️ **D-Bus Архитектура**
  Проект разделен на две части:
  * **Daemon** (`izighost-daemon`): Фоновый сервис на базе `tokio`, отвечающий за логику, API-запросы, OCR, аудио и работу с профилями.
  * **App** (`izighost`): Быстрый и легковесный клиент на базе `egui` (`eframe`).

* 📌 **Wayland Native & GNOME Extension**
  Специальное расширение для GNOME (`window-pin-bridge`), обеспечивающее корректную работу режима *Always-On-Top* в нативной Wayland-сессии.

* 🧩 **Система профилей**
  Создавайте различные профили (personas) со своими системными промптами, настройками LLM и историей контекста.

## 🏗️ Архитектура

Проект состоит из нескольких компонентов:

1. **`app/`** — GUI клиент (HUD), написанный на Rust с использованием `eframe`. Поддерживает темы, настройки и горячие клавиши.
2. **`daemon/`** — Фоновый D-Bus сервис. Управляет состоянием, конфигурацией, аудио-захватом и запросами к нейросетям.
3. **`crates/common/`** — Общие типы данных и определения D-Bus интерфейсов.
4. **`extension/`** — Расширение GNOME Shell для управления окнами (прикрепление поверх других).
5. **`installer/`** — Скрипты и systemd-юниты для удобной установки демона.

## 🚀 Установка

Для сборки и работы IziGhost потребуются следующие зависимости:

### Системные требования:
* Rust & Cargo
* PipeWire (для захвата звука и экрана)
* Tesseract OCR
* GNOME (для Wayland-расширения)
* D-Bus

### Сборка проекта:

```bash
git clone https://github.com/izighost/izighost.git
cd izighost

# Сборка всего workspace
cargo build --release
```

### Запуск демона:
В папке `installer/systemd` находятся файлы для настройки `izighost-daemon` как пользовательского сервиса:

```bash
systemctl --user enable --now izighost-daemon.service
```

### Расширение GNOME:
Для корректной работы плавающего окна (HUD) в Wayland, установите расширение:
1. Перейдите в папку `extension/`.
2. Установите с помощью `gnome-extensions install --force <путь-до-zip>`.
3. Включите расширение.
